# JaalGeometry Demos

This directory contains video demonstrations showing the core meshing algorithms of JaalGeometry in action.

## Demo Videos

- **`mst.ogv`**: Demonstrates the Minimum Spanning Tree (MST) based quadrilateral meshing algorithm.
- **`quadmsh1.ogv`**: Shows the generation of a high-quality all-quadrilateral mesh.
- **`geomquality.ogv`**: Visualizes mesh geometric quality metrics and optimization processes.
- **`gmsh.ogv`**: Demonstrates integration or comparison with Gmsh (a popular mesh generator).
- **`singular.ogv`**: Highlights the handling of topological singularities in quad/hex meshes.

## How to Play
The videos are in OGV (Ogg Video) format and can be played using VLC media player or most modern web browsers.
